# Progetto Laboratorio: Pizzeria Bella Napoli 🍕

Benvenuti nel kit di sviluppo per il laboratorio scolastico! Questo template fornisce la struttura HTML5 e il foglio di stile CSS per la **Pizzeria Bella Napoli**.

## Struttura del Progetto
```text
pizzeria_bella_napoli/
│
├── index.html         # Pagina principale del sito web
├── css/
│   └── style.css      # Foglio di stile CSS personalizzato (tema napoletano)
├── img/               # Cartella per le immagini delle pietanze
└── README.md          # Guida per il laboratorio scolastico
```

## Attività per gli Studenti (Cosa completare)
Il template è già completamente strutturato e funzionante. La sezione **Pizze** è già sviluppata con 2 prodotti completi (Margherita e Marinara).

Il compito della classe è completare le sezioni rimanenti:
1. **Bevande:** Aggiungere 2 bevande (foto, descrizione e prezzo) replicando la struttura HTML della sezione pizze.
2. **Dolci:** Aggiungere 2 dolci tipici napoletani (foto, descrizione e prezzo) replicando la struttura HTML.
3. **Immagini:** Inserire le immagini reali nella cartella `img/` o aggiornare i percorsi.

## Come testare il progetto in locale
1. Decomprimere la cartella sul proprio computer.
2. Aprire la cartella con un editor di codice (es. **VS Code**).
3. Per visualizzare la pagina in tempo reale con aggiornamento automatico, si consiglia di installare l'estensione **Live Server** in VS Code, oppure aprire direttamente il file `index.html` con qualsiasi browser web (Chrome, Firefox, Edge).
